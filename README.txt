A ROSE FOR YOU — Romantic Proposal Website
===========================================

FILES
-----
index.html   Main website structure
style.css    Responsive design and animations
script.js    Longer shayari generator and interactions

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the extracted rose_proposal_website folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.

FEATURES
--------
- Animated rose, glow, sparkles and floating effects
- 1,000 longer, complete shayari combinations in Hindi
- 1,000 longer, complete shayari combinations in English
- 1,000 longer, complete shayari combinations in Hinglish
- Previous, Next and Surprise Me controls
- Language switcher
- Proposal reveal with Yes / Let Me Think responses
- Falling rose petals and celebration animation
- Responsive layout for mobile, tablet and desktop
- No installation or build tools required

CUSTOMIZATION
-------------
Edit the poem arrays near the top of script.js to customize the poetry.
Edit text in index.html and visual styling in style.css.

NOTE
----
The 1,000 poems per language are generated by combining three complete
poetic stanzas. Google Fonts load when internet is available; local fallback
fonts are used otherwise. The website itself works without package installs.
